# Эмулятор UNIX-подобной командной строки (Вариант 29)

Кроссплатформенный эмулятор UNIX-подобной командной строки на Python. Программа использует виртуальную файловую систему (VFS), загружаемую из CSV-файла в оперативную память. Все изменения выполняются только в памяти и не затрагивают реальные файлы компьютера или исходный CSV.

## Поддерживаемые команды

- `ls` — просмотр содержимого каталога; `-l` показывает тип, владельца и группу.
- `cd` — переход в каталог.
- `pwd` — вывод текущего пути в VFS.
- `cat` — вывод текстового файла.
- `uniq` — фильтрация соседних повторяющихся строк; `-c` выводит количество, `-d` — только повторяющиеся, `-u` — только уникальные строки.
- `du` — подсчёт размера файлов и каталогов; `-a` выводит файлы и каталоги, `-h` включает удобный формат, `-s` — только итог.
- `touch` — создание пустого файла; `-c` запрещает создание отсутствующего файла.
- `chown` — изменение владельца и/или группы; `-R` применяет изменение рекурсивно.
- `exit` — завершение эмулятора.

## Запуск

Требуется Python 3.10 или новее. Из корневой папки проекта выполните:

```bash
python shell.py
```

По умолчанию используется `vfs.csv`. Для запуска единственного демонстрационного сценария:

```bash
python shell.py --startup-script startup.sh
```

Можно указать собственный CSV, приглашение командной строки и стартовый сценарий:

```bash
python shell.py --vfs path/to/vfs.csv --prompt "user@vfs:/$ " --startup-script startup.sh
```

Параметры `--vfs` (также `--vfs-path`), `--prompt` и `--startup-script` (также `--script`) задают источник VFS, приглашение и файл команд соответственно.

## Виртуальная файловая система

Файл `vfs.csv` содержит столбцы `path`, `type` и `content_base64`. Каталоги задаются типом `dir`, файлы — типом `file`. Содержимое файлов хранится в Base64, что позволяет безопасно представлять как текстовые, так и бинарные данные. Вся структура и содержимое загружаются в оперативную память при старте.
